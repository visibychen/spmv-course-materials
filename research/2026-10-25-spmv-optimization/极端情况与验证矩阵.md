# 极端情况与验证矩阵

以下为下一轮实现的测试设计，**尚未生成全部输入或测量新算法**。方法出处见 [资料索引](资料索引.md)，选择逻辑见 [优化方案](优化方案v1.md)。既有一个均匀随机矩阵不能代替这些覆盖。

## 1. 性能分布与反例

| 情况 | 暴露的问题 | 计划输入 / 对照 | 处理原则 |
| --- | --- | --- | --- |
| 当前大矩阵：每行恰好 8 项、全局分散列 | 短行开销、间接访问 | 原 12M×12M、96M nnz；完整保留校验和 | 首先比较 CSR 标量 / 收集策略 / SELL8 / SELL16；调度均衡已成立 |
| 行长 1、2、4、7、8、9、15、16、17 | SIMD 利用率和尾部阈值 | 小规模全覆盖，再选 2/8/16 做大规模；控制列分布 | 不把“8 项特殊优化”说成泛化收益 |
| 行长 32、64、256 | 行内 SIMD 与跨行 SIMD 的交叉点 | 等行长矩阵，固定 nnz 或分别标注尺寸 | 长行可能重新适合行内归约，保留 CSR |
| 相同行长但列为窄带 / 全局随机 / 热点集合 | 局部性与指令成本分离 | 固定形状、值和 nnz，仅改变列分布，所有 x 采用非均匀值做正确性检查 | 检查候选是否只对一种访问模式有效；缓存分块不能默认用于带状输入 [P4] |
| 大量短行与少量长行混杂 | 连续行划分不平衡、SELL 填充 | 1% 行长 1024，其余行长 4；长行先聚集，再打乱 | 按工作量划分与局部排序分别消融，避免把两个因素混成一个 |
| 一个巨行，其余极短 | 行不能拆分、slice 被巨行撑大 | 8 行中一行长 1,000,000，其余长 1，列数足够且坐标合法；再做更大 m 的版本 | C=8 填充倍率接近 8；纯行分区、dynamic 都不能拆一行。评估 merge，SELL 拒绝或回退 [P3, C3] |
| 巨行位于首 / 中 / 尾、跨多个线程块 | 分段边界及合并 | 同一结构移动巨行位置，1/12/24 线程 | 每个 y 只能在合并后加旧值一次，scratch 按实际线程数分配 |
| 99% 空行且集中 / 均匀散布 | 仅按 nnz 平衡忽略行扫描 | m=1M，只有 1% 行各 8 项；另选 m≫nnz | 工作模型包含行开销；merge 同时处理 row boundaries 与 nnz [P3] |
| 行长全等但矩阵可驻留缓存 | 启动、同步、分派成本 | n=1K、32K 等，不与大矩阵混算平均加速 | 小任务可保留单线程 CSR；转换和调参容易不回本 |
| 规则稠密小块 | BSR / 寄存器块是否适合 | 2×2、4×4 真稠密块，与同 nnz 随机矩阵对照 | 先测块占用率，再决定是否研究 BSR；不是当前随机输入默认方案 |
| 极高密度 | CSR 元数据成本 | 内存可承受的小矩阵，逐步增加密度 | 记录何时稀疏方案不合适；切换 dense BLAS 属扩展，不掩盖转换成本 |
| m≠n，极高 / 极宽矩形 | x/y 尺寸与置换混淆 | 5×7、17×3、3×17，加可承受的大矩形 | row_perm 与 col_perm 独立；不存在通用的同一方阵 P 套法 |
| 结构化矩阵与打乱后的同一矩阵 | 重排的有效区间 | 已有局部性版本 / 随机置换版本，保留已知 P/Q | 区分“恢复人为打乱的结构”与改善天然随机结构 |

这些构造只确定结构和正确性参考，不能预先当作某算法一定更快的证据。参数选择是本项目测试设计，不是论文通用阈值。

## 2. 边界、数值与资源

| 边界 | 必须检查的行为 |
| --- | --- |
| m=0、n=0、nnz=0、全部空行 | 不能读取不存在的 x、计算非法 padding 索引或依赖 `malloc(0)` 返回非空；原始 / 优化路径应明确成功空操作或明确报错，并分别记录 |
| nnz=0 且 `--flops>0` | 原循环的 FLOPs 条件永远无法满足，存在不终止风险。应有前置校验 / 特判，不能静默无限循环；此类健壮性修复单独测试与记录 |
| m 小于线程数、m 不是 C 的倍数 | 空任务和最后不足一个 slice 的 lane；所有线程按一致协议进入屏障和退出，禁止尾部越界 |
| 最长行刚好跨分区边界、同一行跨 3 个以上分区 | split / carry 合并与 y+=Ax 语义；不能只测试一行最多跨两个线程 |
| 存储中的重复坐标和显式零 | 保留当前实际 CSR 项序，合并重复或删除显式零会改变某些浮点 / NaN 行为，不能无声明处理 |
| x 含 NaN / Inf，特别是 x[0] | SELL 的补零项若无条件访问 x[0]，0×NaN/Inf 会污染结果。无效 lane 必须禁止相应访问 / 运算，或明确回退；不能只把列号改 0 便宣称正确 |
| 有效非零项自身为 0，乘 Inf；输入有 NaN | 与“虚构 padding 零”区分；有效项仍应遵循选定数值语义。检查有限 / 非有限分类，不能仅调用普通 allclose |
| 强消去、大/小量级混合、很长行 | 独立宽精度参考，报告最大绝对误差、相对误差和残差尺度；容差结合行长与精度制定，不为求快统一放宽到任意 1e-3 |
| 非零初始 y、R>1 | 保留每次 `y += Ax`；正确性参考逐次执行累加。数学式 y0+R·Ax 不等于一般浮点下逐位等价；禁止用一次乘法代替 R 次 |
| -0、subnormal、浮点异常 / 舍入要求 | 严格行为要求走原始回退或匹配编译设置；全局 fast-math、FTZ/DAZ、FMA 改动应单独披露 [D1] |
| nnz / 偏移超过 2^31，m+nnz、slots×元素大小接近上限 | 保留 int64 行指针；检查加法、乘法和 size_t 溢出；用不分配巨量数据的边界检查用例验证。当前 m/n/列索引受 int32 范围约束，不声称支持任意维度 |
| 长尾令 SELL 槽位数暴涨、内存分配失败 | 转换前计算 slots 和峰值预算；包含原 CSR、派生格式、映射与 scratch；拒绝转换并一致回退，不生成半完成句柄 |
| x 本身就放不进可用内存 | 回退 CSR 也无法解决 x 分配失败；应清楚报资源错误，外存算法不在 v1 范围 |
| 矩阵值或结构更新、x 每轮变化 | 计划不得缓存 Ax；结构更新使划分与布局失效，数值更新需要刷新派生值，相关成本计入。固定 x 的基准特例不能偷换为通用接口 |
| x/y 内存重叠 | 原 restrict 契约不支持通用原地 SpMV；新接口不能悄悄承诺支持，应约束或检测，而不是按线程边界碰运气 |
| 非 f32、int / complex 类型、无 AVX2 主机 | 初期显式回退原内核，不能对未适配类型套 f32 布局；ISA 分派需检查支持 [D2] |
| 对称 / skew / Hermitian / pattern 文件 | 核对文件头和 `--include-symmetric-part`，统计转换后的实际 nnz；同一完整算子公平对比，不把只读半边称为加速 [D7] |
| f64 输入由 `real` 导入 | 当前实现 real 坐标先以 float 读取，再转 f64不能恢复已丢精度。区分读取量化 / 范围问题和内核误差 |
| 线程数、绑定或运行时团队变化 | 计划与实际团队数匹配，T 个 scratch / 分区正确；不能缓存旧 T 的划分后直接改 OMP_NUM_THREADS |
| 多 NUMA、first-touch 与 SMT | WSL 当前报告单 NUMA，不推断宿主机完整拓扑。跨节点测试时单独记绑定 / 触页策略；不将 NUMA 调整收益混为算法收益 |

## 4. 控制实验规模

先在小输入完成全部正确性用例，再按“均匀随机、带状局部、长尾、巨行、空行、真实矩阵”逐类扩大。初筛只用 1/12/24 线程；有明确收益的候选再补 2/4/8 的扩展曲线，避免把所有格式、线程、参数和输入一次做成无法分析的全排列。

大矩阵先做 R∈{1,9,100} 的成本核算；R=1000 只在总运行时间可接受的中小矩阵上测试。既有 baseline 不覆盖的组合重新测原程序，不能凭历史数据插值。

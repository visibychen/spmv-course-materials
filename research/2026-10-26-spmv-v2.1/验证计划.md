# v2.1 验证与验收计划

日期：2026-10-26。以下为**待实施计划**，不能写作已经通过。本轮仅复算1640条既有v2记录。

## 1. 先拆分开发集和新保留集

旧v2的22个极端输入、两组校准、7个合成保留输入和两组真实输入，已被本次设计使用，全部改列v2.1开发/回归集。**不再称它们为v2.1未见过的保留集**。

实施时先用开发集和校准生成器确定模型、切换点、团队集合及回退余量，再冻结代码/配置SHA。新保留集使用新种子、未用于校准的尺寸、不同长行位置与局部性组合；生成后禁止用成绩反向调参。若失败后修改，再追加新保留集并保留失败轮次。

| 必测组 | 结构变化 | 要揭露的问题 |
| --- | --- | --- |
| 超大均匀 | 沿用主9600万nnz；另加整列范围抽样、新种子、非8短行 | 保留主收益，避免只适配分段8项生成器 |
| 临界工作量 | 原32768执行阈值和100000准备阈值两侧；不同m/nnz比 | 阈值突变、检查团队误选 |
| 巨行 | 1/2/3/8条；均匀/相邻/同静态分区/不同分区；长行从千到百万项 | 最长行相同而最佳团队/后端不同 |
| 长尾 | 集中/散布/多热点，新长尾分布 | 保留work收益，避免统计相近但分配不同 |
| 空行 | 0/50/90/99/100%；连续/周期/随机；非空行位置在分区边界 | 压缩/回退成本、空行输出语义 |
| 局部性 | 带状、热列、全范围随机，宽x与小x；相同m/nnz | 不能仅由nnz预测随机访问延迟 |
| 真实矩阵 | 保留两例回归，另选至少4例不同应用/行长/规模 | 真实退化、对称展开及数值尺度 |

新真实矩阵先查来源和许可，记录原文件哈希、类型、stored/expanded nnz。若本机资源或下载条件限制，列明未覆盖项，不用旧两例冒充新集。

## 2. 对照和消融

固定原始master `9352c86`、v1 `f089579`、v2 `9b652e8`。v2.1建立后记录完整SHA、源码和构建标识。两层对照都保留：

1. 工程对照：各自独立程序，输入/精度/R/绑定一致；P、调参、E、D、全程wall分别记，总成本逐样本相加再汇总。
2. 同二进制诊断：原始、匹配FP通用CSR、short8、局部SIMD、merge使用相同预热/初始化，轮转执行位置，记录多进程复现。稳态不能替代独立程序总成本。

必要消融逐项启用：仅单团队prepare；仅prepare串/并行选择；仅R/团队策略；仅分区缓存；仅局部长行SIMD；仅merge坐标缓存；仅归并所有者；可选空行元数据。某项失败不靠组合后隐去其负结果。

巨行同时对照v1-pack或等价独立端口；局部SIMD同时对照原始自动向量化及有序标量。均匀8项必须保留同FP通用CSR，避免再次把short8标签当作独立收益。空行组包含original、rows/work/merge及强制串行/中间线程候选。

## 3. 性能协议

- 主目标与已暴露严重退化组：至少10组相邻随机AB/BA独立进程对。v2.1/原始和v2.1/v2分别配对，不能将不相邻的三方样本任意配成一对。其他组合先5个独立进程，接近门槛或波动大则在事先约定的扩样规则下追加，不删慢样本。
- R=1/9/100，先导增加R=0接口检查；零nnz不使用正flops驱动。模型回本点若要宣称，需在它两侧重新测R，而非仅代公式。
- 校准线程含1/2/4/8/12/24及用户上限；正式对照分别报告同请求上限、实际T，以及原始在同一允许集合中的最佳已测T。对比最佳值的选点过程本身也会产生选择偏差：在校准集定规则，正式数据只验规则；未覆盖线程不要称全局最优。
- 沿用OMP_DYNAMIC=FALSE、PLACES=cores、PROC_BIND=spread、WAIT_POLICY=PASSIVE作为主条件；ACTIVE仅另表鲁棒性消融。记录cpuset、实际团队、编译器/ISA、profile版本、频率/负载信息和时钟精度。WSL不锁宿主频率时明确限制，所有基准顺序运行。
- 同时报告中位数、范围、相邻配对比值及固定种子20000次配对bootstrap区间。配对加速比中位数与两个总时间中位数之比不能混称同一统计量。
- 报告各尺寸/结构组的胜负、最差退化、超过5%退化的条件数；不能让小矩阵串行的数百倍收益掩盖双巨行的退化。总体几何平均若使用，分组与权重在计时前声明，同时保留逐例结果。

## 4. 正确性与生命周期

| 方面 | 必须检查 |
| --- | --- |
| 重复语义 | 非零初始y、每次变化x/values、R0/1/3/9；不缓存Ax，不以R*Ax替代真实调用 |
| 浮点 | 消去、不同数量级、NaN/Inf、subnormal、±0、尾部1/7/8/9/17；记录FTZ/DAZ与舍入设置。严格顺序对匹配FP参考；重组路径用逐行绝对值和/行长误差界与独立高精度参考 |
| 空行 | 负零y在空行上的加零结果；全零/零维；不能以不写y冒充相同语义 |
| 分区/归并 | 两个切点落同一巨行、零长片段、恰好行界、多线程同一行；每个非零元算一次、每行旧y加一次、调用结束可见 |
| 团队 | prepare/execute T不同、容量上/下变化、嵌套与线程限制、全部线程统一回退；无死锁 |
| 结构计划 | 显式重建结构后的边界、维度/类型变化、换存储、原地改结构的契约；只换数值不复用旧Ax。不能声称指针检查实现自动版本保护 |
| 安全 | 非单调row_ptr、非法列、64位坐标和乘加溢出、非法R/flops、分配失败、预算边界；不为验证64位而真的分配超大数组 |
| 兼容 | f64/整数/复数/pattern及不支持模式按原始回退；非法参数不得让部分线程绕开屏障 |

新增核心能力应有必要的单元/CLI验证，native与portable构建、ASan/UBSan覆盖变更路径。正式计时关闭诊断与sanitizer。若没有TSan/硬件计数支持，说明缺失，不把普通通过等同于证明无竞争。

## 5. 验收门槛：先冻结，再看新数据

下面是建议的项目工程门槛，**不是论文结论，也不是已经达到的成绩**：

1. 正确性与安全必过；任何改变行内顺序的路径都明确数值模式，不混入strict-order成绩。
2. 主大矩阵R9：对同批原始最佳已测线程，仍至少降低5%总成本，配对区间支持收益；对v2同批总成本的退化控制在3%以内。不依靠删去P或转换来达标。
3. 双巨行、empty99、空行聚集、BCSSTK18：优先目标是相对同请求上限的原始total不超过5%退化，同时显著优于原v2的严重退化；若仍无法满足，则相关结构不自动升级，保留手动候选与失败记录。即使回退original也需把已支付的验证/选择P计入，不能假定回退自动零开销。
4. 新保留集：超过5%的退化条件数比v2少，最差退化收敛；同批比较条件和阈值先冻结。若只是以少数大收益抵消更多退化，不接受为“稳健auto”。
5. 普通/merge计划额外元数据目标保持O(T)、硬预算沿用4MiB。空行/长行列表若引入O(k)必须单列、计入预算并能分配失败回退；不把进程RSS峰值当作新增元数据大小。
6. 调参成本显式可见。未知profile/结构时保守行为可解释。新策略达标前默认仍original；若只能修复某类输入，按该范围交付。

数据不支持时允许得出“v2.1这条候选无效”。本设计没有预先承诺修复全部矩阵或某个具体加速倍数。
